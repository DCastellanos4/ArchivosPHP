# Archivos PHP 🐘

Este repositorio contiene una colección de scripts y ejercicios desarrollados en **PHP**, enfocados principalmente en la manipulación de archivos, procesamiento de datos y fundamentos del lenguaje.

## 🚀 Contenido del Repositorio

El proyecto incluye ejemplos prácticos sobre:
* **Lectura y Escritura:** Uso de funciones como `fopen`, `fread`, `fwrite` y `file_get_contents`.
* **Gestión de Directorios:** Creación, eliminación y listado de carpetas.
* **Procesamiento de Formularios:** Cómo recibir datos y almacenarlos en archivos de texto o CSV.
* **Lógica de Programación:** Estructuras de control, funciones y manejo de arrays aplicados a archivos.

## 🛠️ Requisitos

Para ejecutar estos scripts, necesitarás tener instalado un entorno de servidor local:
* [PHP](https://www.php.net/) (Versión 7.4 o superior recomendada)
* Un servidor web como **Apache** o **Nginx** (o herramientas como XAMPP, Laragon o Docker).
